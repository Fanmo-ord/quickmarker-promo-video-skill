# 故障处理

## 依赖准备

运行启动命令并读取环境报告：

```bash
python3 scripts/run_pipeline.py --workspace "<工作区>" start --install
```

报告会列出 Git、Python、Node.js、FFmpeg、剪映和两个依赖 Skill 的状态。根据 `next_action` 补齐对应依赖后继续。

## 素材数量较少

使用仓库预置官网资料、产品截图、二维码和运营定位生成首版方案，同时在交付清单中列出优先补充的镜头。

## 选题相似度较高

从教师痛点、产品能力、证据形式、使用场景或平台叙事结构中更换一个核心维度，再次检查选题池。

## 字幕层级

主片提供干净画面和视觉标题；剪映生成一层与旁白同步的底部字幕。验收时检查字幕可读性、时间轴和安全区。

## 画幅与构图

剪映素材采用铺满竖屏画布的 1:1 缩放关系，字幕叠加在底部安全区。验收时检查主体比例、裁切和留白。

## macOS 导出

AI 打开并验证草稿，用户点击“导出”，随后 AI 读取 MP4 并完成媒体验收。

## 草稿恢复

保存当前草稿副本，重新生成同一项目版本，恢复素材路径、旁白、字幕、混音和封面后执行打开验证。
