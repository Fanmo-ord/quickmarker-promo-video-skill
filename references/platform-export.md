# 剪映导出策略

## macOS

`jianying-editor-skill` 负责生成、修复和打开剪映草稿。自动化完成后，AI 应先验证草稿可以打开、素材在线、画布为竖屏、主画面未缩小、字幕只在底部，然后明确提醒用户：

> 剪映草稿已经准备好，请在剪映中点击“导出”。导出完成后把文件留在指定目录，我会继续自动验收。

不要声称 macOS 已自动导出 MP4。用户导出后运行最终验证。

## Windows

可以使用剪映 Skill 的自动导出能力，建议输出到：

```text
04-视频项目/03-成片/<project-id>/<project-id>.mp4
```

自动导出只有在以下条件全部满足后才算成功：文件存在、时长大于 0、分辨率正确、有音轨、能正常解码。仅看到剪映完成提示不算验证。

## 两个平台共同要求

- 不覆盖旧版本；递增 `v2`、`v3`。
- 输出目录同时保留封面、脚本、平台文案和 `delivery-manifest.json`。
- 二维码已经在主片阶段完成；导出阶段只能验收，不能补做。
